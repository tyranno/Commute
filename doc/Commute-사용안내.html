Commute 사용 안내

Commute — 출퇴근 자동 기록 앱 사용 안내

버전 0.1.0 · Android 7.0(API 24) 이상

⚠️ 먼저 꼭 읽어주세요 — 이 앱의 시간은 “대략값”입니다

이 앱은 출입 게이트를 찍는 방식이 아니라, 회사 Wi-Fi(AP) 또는 사무실 비콘(BLE) 신호가 잡히는 “영역 안에 있는지”로 출근/퇴근을 추정합니다. 그래서 앱이 기록하는 시각은 실제 출입 시각과 차이가 날 수 있습니다.

오차 원인 무슨 일이 생기나
감지 주기(약 1분) 신호를 1분에 한 번 확인합니다. 실제로 자리를 뜬 시각과 최대 1분 차이가 납니다.
신호 꼬리(tail) 책상을 떠나 짐을 싸고 복도·엘리베이터로 이동하는 동안에도 신호가 잡혀, 퇴근이 실제보다 늦게 찍힐 수 있습니다.
신호 세기·간섭 벽·사람·기기 위치에 따라 신호가 잠깐 끊기거나 늦게 잡혀, 출근이 늦게/퇴근이 이르게 찍힐 수 있습니다.
절전(Doze)·재부팅 밤사이 화면을 오래 끄거나 폰이 꺼지면 자동 퇴근 처리가 지연될 수 있습니다.

따라서 이 앱의 기록은 참고용 근태 보조 자료이며, 공식 근태·급여 산정 기준으로 그대로 쓰기에는 부적합할 수 있습니다. 실제와 다르면 아래 기록 수정 방법으로 직접 고쳐서 쓰세요. 정확한 퇴근 시각이 필요하면, 자리를 뜰 때 “퇴근 마진”(설정 → 근무 규칙)을 활용해 꼬리 오차를 몇 분 앞당길 수 있습니다.

1. 설치

  1. 배포받은 Commute-0.1.0.apk 파일을 폰으로 옮깁니다(메신저/메일/USB 등).
  2. 파일을 탭해 설치합니다.
  3. “이 출처의 앱 설치” 차단 안내가 뜨면 → 설정에서 해당 앱(파일 관리자/브라우저)에 “이 출처 허용”을 켠 뒤 다시 설치하세요.
  4. 설치 후 첫 실행 시 아래 권한들을 모두 허용해야 자동 감지가 동작합니다.

이미 설치돼 있고 업데이트만 하는 경우에도 같은 APK를 그대로 설치하면 됩니다. 기존 출퇴근 기록은 유지됩니다.(단, 서명이 다른 APK로 덮어쓰면 재설치가 필요하니, 항상 같은 배포처의 APK를 쓰세요.)

2. 최초 설정 (한 번만)

2-1. 권한 허용

앱이 백그라운드에서 신호를 확인하려면 다음 권한이 필요합니다.

  • 위치 — “항상 허용” : Wi-Fi/비콘 스캔에 안드로이드가 위치 권한을 요구합니다. 꼭 “앱 사용 중에만”이 아니라 “항상 허용” 으로 설정해야 백그라운드 감지가 됩니다.
  • 주변 기기(블루투스) : 사무실 BLE 비콘을 감지할 때 사용합니다.
  • 알림 : 근무 감지가 켜져 있음을 알리는 상단 알림(상시 표시)입니다.
  • 배터리 최적화 제외 : 폰이 앱을 절전으로 잠재우지 않도록, 요청이 뜨면 허용하세요. (설정 → 배터리 → 앱별 관리에서 Commute를 “제한 없음”으로 두는 것을 권장)

2-2. 회사 감지 대상 등록 (설정 → 감지 탭)

오른쪽 위 톱니바퀴(⚙) → 감지 탭에서 하나 이상 등록합니다.

  • 회사 Wi-Fi(AP) 등록 : 사무실에서 잡히는 회사 공유기를 골라 등록합니다. 실제로 그 Wi-Fi에 연결돼 있지 않아도, 신호가 스캔되면 근무중으로 봅니다.
  • 회사 비콘(BLE) 병행 감지 (선택) : 사무실에 설치된 검출용 비콘이 있으면 “주변 비콘 검색”으로 찾아 등록합니다. Wi-Fi가 안 잡힐 때 비콘으로 보완합니다. (둘 중 하나라도 잡히면 근무중으로 판정합니다.)

비콘은 감지 전용입니다. 앱이 비콘을 켜거나 끄는 등 제어하지 않습니다.

3. 홈 화면 보는 법

상단 카드에 현재 상태가 표시됩니다.

  • 근무중 / 자리 비움 / 퇴근 : 지금 신호가 잡히는지에 따라 바뀝니다.
  • 회사 와이파이 / 회사 비콘 : 어떤 신호로 감지 중인지, 블루투스·Wi-Fi 아이콘으로 표시.
  • 맨 오른쪽 토글 : 자동 감지 켜기/끄기.

아래 탭은 현황 / 기록 / 연차·외출 3개입니다.

현황 탭

  • 오늘 근무시간 : 오늘 인정된 순근무 시간(점심 제외). 탭하면 “점심 포함”으로 잠깐 토글됩니다.
  • 이번주 총 근무시간 : 이번 주(월~일) 합계. 탭하면 “이번주 초과근무(±)” 로 약 10초간 바뀌었다가 자동 복귀합니다(다시 탭하면 즉시 복귀).
    • 초과근무 = 그 주 기록이 있는 날만 Σ(그날 인정시간 − 8시간). 오늘(진행 중인 날)은 제외됩니다.
  • 이번주 출퇴근 시간 그래프 : 날짜별 출근~퇴근 막대.
    • 파란 막대 = 근무 시간대, 연한 밴드 = 점심시간,
    • 막대 상단 앰버(주황) = 그날 8시간을 초과한 구간,
    • 점선 테두리의 빈 막대 = 연차/반차/외출(시간대에 맞춰 표시).
    • 막대를 탭하면 그날 상세(출근/퇴근/인정시간)가 뜹니다.

기록 탭

  • 과거 출퇴근 기록 목록. 상단 칩(이번주 / 최근 2주 / 이번달 / 최근 3개월 / 최근 6개월 / 전체) 으로 기간을 한 번에 고릅니다.
  • 각 기록을 탭하면 출근/퇴근 시각을 직접 수정할 수 있습니다(오차 교정용).

4. 연차 · 반차 · 외출 관리 (연차·외출 탭)

오른쪽 아래 + 버튼 으로 추가합니다.

종류 인정 시간 비고
연차 하루 8시간(480분) 인정
오전 반차 4시간(240분) 인정 기본 09:00~13:00 (설정에서 조정)
오후 반차 4시간(240분) 인정 기본 14:00~18:00 (설정에서 조정)
외출 (종료−시작) − 겹치는 점심 시간 시작/종료 시각을 직접 입력
  • 등록한 연차/반차/외출은 총 근무시간·초과근무 계산에 자동 반영되고, 홈 그래프에 시간대에 맞춰 빈 막대로 표시됩니다.
  • 반차/연차는 정의상 이미 점심을 뺀 순근무 기준이라 별도 점심 차감이 없습니다. 외출만 점심시간과 겹치는 만큼 자동으로 빼줍니다.

연구소 운영방안에 연차/반차/외출 시각 규정이 별도로 없어, 일반 관행값 (오전 09~13 / 오후 14~18)을 기본으로 넣었습니다. 실제 규정이 다르면 설정 → 근무 규칙 → “반차 시간대”에서 바꾸세요.

5. 기록 수정(연차·반차·외출)

앱 시간이 실제와 다를 때:

  1. 기록 탭 → 해당 날짜의 출근/퇴근 기록을 탭 → 시각 수정 → 저장.
  2. 하루 종일/반나절 부재는 연차·외출 탭에서 연차·반차·외출로 등록.

수정하면 총 근무시간·초과근무가 다시 계산됩니다.

6. 설정 상세 (⚙ → 근무 규칙 탭)

  • 자리 비움 인정 기준 : 잠깐 신호가 끊겨도 “자리 비움”으로 보지 않을 유예 시간.
  • 자동 퇴근 : 오래 신호가 안 잡히면 자동으로 퇴근 처리.
  • 퇴근 마진(0~10분) : 신호 꼬리 오차 보정. 퇴근 시각을 설정한 분만큼 앞당겨 기록합니다.
  • 점심시간 : 순근무에서 제외할 점심 구간(기본값 설정).
  • 주말 표시 / 반차 시간대 등.

설정은 자동 저장됩니다(별도 저장 버튼 없음). 화면을 벗어나면 반영됩니다.

7. 데이터 백업 / 복구 (⚙ → 데이터 탭)

  • 백업 : 기록을 JSON 파일로 내보냅니다. 폰 교체·초기화 전에 백업해 두세요.
  • 기록 로그에서 복구 : 앱이 별도로 남기는 기록 로그에서 누락분을 되살립니다 (앱 재설치·DB 손상 시 대비용). 복구 가능한 건수가 있으면 버튼이 활성화됩니다.

8. 자주 묻는 질문

Q. 출근/퇴근이 실제와 몇 분 다르게 찍혔어요. 정상 범위입니다(맨 위 오차 설명 참고). 기록 탭에서 직접 수정하세요.

Q. 사무실에 있는데 “퇴근”으로 뜹니다. 회사 Wi-Fi/비콘이 등록됐는지(설정 → 감지), 위치 권한이 “항상 허용”인지, Wi-Fi·블루투스가 켜져 있는지 확인하세요. 폰 절전에서 앱이 “제한 없음”인지도 확인.

Q. 밤새 폰을 꺼두면 퇴근이 안 찍혀요. 절전/재부팅으로 자동 퇴근이 지연될 수 있습니다. 다음 날 앱을 열면 오래된 세션이 정리되며, 필요하면 기록 탭에서 퇴근 시각을 직접 넣으세요.

Q. 이 기록을 그대로 근태로 제출해도 되나요? 권장하지 않습니다. 영역 감지 특성상 오차가 있으니 참고 자료로 쓰고, 공식 제출 전에는 반드시 본인이 실제 시각과 대조·수정하세요.

문의/개선 요청은 배포자에게 전달해 주세요.
