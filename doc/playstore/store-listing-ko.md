# Play 스토어 등록 정보 (한국어)

## 앱 이름
Commute

## 짧은 설명 (80자 이내)
Wi-Fi·BLE로 출퇴근을 자동 기록하는 개인용 근무시간 관리 앱

## 전체 설명

**Commute는 등록해둔 Wi-Fi 네트워크나 BLE 비콘을 기준으로 출근·이석·복귀·퇴근을 자동으로 기록해주는 개인용 근태 관리 앱입니다.**
매번 수동으로 출퇴근을 체크할 필요 없이, 정해둔 장소(사무실, 특정 공간 등)의 Wi-Fi나 BLE 신호가 감지/미감지되는 것만으로 근무 상태가 자동으로 기록됩니다.

**주요 기능**
- Wi-Fi SSID 또는 BLE 비콘을 기준으로 출근/이석/복귀/퇴근 자동 감지 (복수 네트워크·비콘 등록 가능)
- 근무 인정 시간, 이석 허용 기준 등 나만의 근무 규칙을 설정에서 직접 조정
- 공휴일 자동 반영 + 사용자 지정 휴일 등록
- 주간/일별 근무 통계 확인
- 감지 오류를 직접 확인할 수 있는 진단 로그
- 한국어/영어 다국어 지원
- 로그인/회원가입 없이 바로 사용 가능

**개인정보 보호 원칙**
- 모든 출퇴근 기록과 설정은 기기 안에만 저장되며, 개발자의 서버로 전송되지 않습니다.
- 광고, 분석, 크래시 리포팅 등 어떠한 제3자 SDK도 포함되어 있지 않습니다.
- 위치 권한은 Wi-Fi/BLE 스캔을 위한 안드로이드 시스템 요구사항으로만 사용되며, GPS 좌표를 수집하지 않습니다.
- 자세한 내용은 개인정보처리방침을 참고해 주세요.

**이런 분께 추천합니다**
- 유연근무제, 재택/사무실 혼합 근무 등으로 출퇴근을 자동으로 기록하고 싶은 분
- 매일 수기로 근태를 기록하기 번거로운 분
- 개인 데이터가 외부 서버에 저장되지 않기를 원하는 분
