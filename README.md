# Commute

회사 와이파이 연결/해제를 감지해서 출근·퇴근을 자동으로 기록하는 순수 코틀린 + Jetpack Compose 네이티브 안드로이드 앱입니다.

## 주요 기능

- **회사 와이파이 등록**: 현재 연결된 와이파이를 버튼 한 번으로 등록하거나, 상태 카드의 와이파이 아이콘을 눌러 주변 와이파이를 스캔한 목록에서 선택해 등록(연결 없이도 등록 가능)
- **4단계 상태 표시**: 홈 화면 상태 카드가 "출근 인식됨"(와이파이는 감지됐지만 아직 서비스가 공식 기록 전)·"근무중"·"자리비움"(세션은 유지 중인데 지금 감지가 안 됨)·"퇴근" 네 가지로 표시, 현재 시각이 설정된 점심시간 안이면 "· 점심시간"을 덧붙여 표시
- **자동 감지**: 포그라운드 서비스가 1분마다 와이파이 스캔 결과를 폴링 — 실제로 그 와이파이에 **연결**되어 있지 않아도, 주변에서 **검출**만 되면 출근으로 인식(사원증 태그처럼 반경 안에 들어오면 인식되는 방식)
- **출퇴근 자동 기록**: 등록된 SSID가 최초로 검출되면 출근(ARRIVE), 마지막으로 검출된 시각을 퇴근(LEAVE)으로 Room DB에 기록
- **자리비움 구분**: 설정한 "자리비움 인정 기준(분)"보다 짧게 와이파이가 끊겼다 다시 연결되면 퇴근으로 처리하지 않고 자리비움(AWAY)으로 기록 — 기본값은 가산 연구소 운영 방안 문서 기준 10분이며 앱 내 설정에서 조정 가능
- **점심시간 설정**: 설정한 점심시간 구간(기본 11:20~12:20, 실제 운영 중인 점심시간 기준) 동안의 단절은 자리비움 인정 기준과 무관하게 퇴근으로 마감하지 않고, 종료 후에도 자리비움 인정 기준만큼 추가 유예를 둠
- **알림**: 출근/퇴근/자리비움 종료 시 알림 표시
- **재부팅 대응**: 자동 감지가 켜져 있으면 재부팅 후에도 서비스 자동 재시작
- **현황/기록 탭**: 홈 화면 하단에 "현황"(오늘 근무시간·이번주 총 근무시간 + 요일별 출퇴근 타임라인 차트)과 "기록"(이번주 이벤트 스크롤 목록) 탭. 타임라인 차트는 탭 영역의 남은 세로 공간을 전부 채우며, Y축이 시각(07:00~22:00, 근무 인정 시간과 동일한 범위, 2시간 간격 그리드라인)이고 각 요일의 막대가 그날의 첫 출근~마지막 퇴근(또는 근무 중이면 현재 시각까지) 구간을 떠 있는 형태로 표시해, 막대 위치로 "언제" 출퇴근했는지와 막대 길이로 "얼마나" 일했는지를 한 번에 볼 수 있음. 막대를 누르면 그날의 출근/퇴근/근무시간 요약과 상세 기록 다이얼로그 표시. 차트를 좌우로 스와이프하면 지난 주로 넘어가 과거 기록을 볼 수 있고(이번 주보다 미래로는 못 감), "이번주로" 버튼으로 즉시 복귀 가능. 주간 기준은 롤링 7일이 아니라 **월요일에 리셋되는 이번 주**(월~일). 실 근무시간은 ARRIVE~LEAVE 세션 시간에서 설정된 점심시간 구간을 자리비움 여부와 무관하게 항상 차감하고, 점심시간이 아닌 짧은 자리비움(10분 미만)은 근무시간으로 인정해 계산(가산 연구소 규정 반영)
- **기록 수정/삭제/추가**: 오인식된 기록을 눌러 유형(출근/퇴근/자리비움)·날짜·시각을 고치거나 삭제 가능(기록 탭, 현황 탭의 날짜별 상세 다이얼로그 모두에서). 삭제는 실수 방지를 위해 두 번 눌러야 확정됨. 서비스가 놓친 기록은 기록 탭의 "+" 버튼이나 현황 탭 날짜별 상세보기의 "빠진 기록 추가"로 직접 채워 넣을 수 있음
- **근거 문서 보기**: 설정 화면에서 위 규칙들의 근거인 가산 연구소 운영 방안 문서를 앱 안에서 바로 열람 가능 — 내장된 원본 PDF를 기기의 `PdfRenderer`로 직접 렌더링해 이미지로 표시(외부 PDF 뷰어 앱으로 나가지 않음)
- **데이터 백업/복원**: 설정 화면에서 모든 출퇴근 기록과 설정을 JSON 파일로 내보내거나 불러올 수 있음(SAF로 저장 위치 직접 선택 — Room DB/DataStore는 앱 전용 저장소라 앱 삭제 시 함께 사라지므로, 이 파일을 앱 밖에 보관해두면 재설치 후에도 복원 가능)

## 기술 스택

- Kotlin 2.1.0 + Jetpack Compose (Compose Compiler Gradle 플러그인)
- Room (KSP) — 출퇴근 이벤트 저장
- DataStore Preferences — 설정(회사 SSID, 감지 on/off, 현재 상태) 저장
- AGP 8.13.0 / Gradle 8.14.3
- compileSdk / targetSdk 36, minSdk 24

## 빌드

```
.\gradlew.bat assembleDebug --no-daemon
```

또는 `build-apk.bat` 실행 시 빌드 후 연결된 디바이스에 바로 설치됩니다.

필요 환경 변수 (Windows 네이티브 경로):
- `JAVA_HOME=C:\Program Files\Android\openjdk\jdk-21.0.8`
- `ANDROID_HOME=C:\Program Files (x86)\Android\android-sdk`

### 릴리즈 서명

```
.\gradlew.bat assembleRelease --no-daemon
```

TRide 앱과 동일한 인증서로 서명하도록 구성되어 있음(`../TRide/android/app/tride-release.jks`를 `app/tride-release.jks`로 복사해 사용). 서명 정보는 저장소 루트의 `keystore.properties`(gitignore 처리됨, 커밋되지 않음)에서 읽으며, 이 파일과 `.jks`가 없는 환경에서는 서명 없이(unsigned) 빌드됨 — 새 환경에서 릴리즈 빌드를 하려면 두 파일을 직접 준비해야 함.

## 권한

- `ACCESS_FINE_LOCATION` — 연결된 와이파이 SSID 판독에 필요 (Android 8+)
- `ACCESS_WIFI_STATE`, `CHANGE_WIFI_STATE` — 주변 와이파이 스캔 결과 조회 및 수동 검색(재스캔 요청)
- `POST_NOTIFICATIONS` — 출퇴근 기록 알림
- `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION` — 와이파이 감지 서비스
- `RECEIVE_BOOT_COMPLETED` — 재부팅 후 감지 서비스 자동 재시작

## 근무 규칙

`doc/가산 연구소 운영 방안_0923 (1).pdf`(자율출퇴근제 운영 방안)를 근거로 앱이 지원해야 할 근태 규칙이며, 값은 메인 화면 우측 상단 "근무 규칙 설정" 버튼으로 진입하는 별도 설정 화면(`SettingsScreen.kt`)에서 조정 가능(현재 구현된 항목만 표시):

- 자리비움 인정 기준: 10분 (구현 완료, 기본값 조정 가능)
- 점심시간: 11:20~12:20 (구현 완료, 기본값 조정 가능 — 이 구간은 자리비움 인정 기준과 무관하게 퇴근으로 마감하지 않음. 실제 운영 시간 기준이며 가산 연구소 문서에는 명시된 시각이 없음)
- 근무 인정 시간 07:00~22:00: **하한(07:00)만 구현 완료** — 07:00 이전 출근은 근무시간·그래프 막대 모두 07:00부터로 처리. 상한(22:00)은 아직 미구현
- 출근 인정 시간 07:00~13:00, 구간별 휴게시간 공제(4h마다 30분/8h 점심1h/12h+ 1h30m) — 아직 미구현
